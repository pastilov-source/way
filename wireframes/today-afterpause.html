Досі актуальний?

Відкладений крок лишиться на дорозі — до нього можна повернутися.

Екран: Сьогодні · Стан: після паузи — без лічильників і докору · Файл: today-afterpause.html

Job стану: J5 «Повернутися після паузи» — «Коли я на кілька днів випала з роботи над ціллю, я хочу продовжити з того місця, де зупинилась, щоб не починати спочатку.» Ще E3 «Не почуватися винною за порожній день» — «Коли день минув без видимого результату, я хочу не почуватися винною, щоб один такий день не перекреслював решту тижня.» Обидві — Персона 2 (sitemap.md, «Primary і secondary»).

Що змінилось проти базової: над зонами — «З поверненням» без лічильника днів; плаваючий крок питає, чи старий крок досі актуальний; «наступний крок» пропонує найперший крок для продовження; «зроблено сьогодні» — без записів і без докору.

Дані стану: кроків не було з 25 вересня, п'ятниці; останнім тоді записано заднім числом «Структуру другого кейсу». Крок «Дописати вступ…» узято того ж дня, і він переходив з дня на день (sitemap.md, «Крок на сьогодні»). Пропозиція «Перечитати, що вже є в кейсі…» вигадана для цього стану. Скільки днів вважати паузою — відкрито (sitemap.md, «Відкрите», 11); тут шість, але на екрані їх не названо.

Сповіщення: якщо сповіщення ввімкнені, сюди привело одне сповіщення «після паузи» — запрошення зробити найперший крок; тап веде на «Сьогодні». Далі продукт мовчить (sitemap.md, «Сповіщення»). Без сповіщення — той самий стан, коли людина повертається сама.

Куди далі за flow J5:

  • «Висить незроблений крок з до паузи?» так — цей стан → «Він досі актуальний?» так: «Так, продовжити» → Крок із собою → успіх «продовжила з того місця, де зупинилась»
  • ні: «Ні, відкласти» → Сьогодні: наступний крок; старий крок лишається на дорозі відкладеним
  • «Висить незроблений крок?» ні → одразу Сьогодні: наступний крок; плаваючий крок тоді без кроку, окремої сторінки цього варіанта немає
  • «Прийняла найперший крок для продовження?» так: «Взяти на сьогодні» → Крок із собою; ні: «Спершу подивитися дорогу» → Дорога — на паузі
  • Поза J5, flow J0: «Уже зроблено» → Крок із собою — зберігаємо; «Записати» → Сьогодні — зберігаємо
  1. «Кілька днів не було руху»
  2. «Сповіщення ввімкнені?» — так: одне сповіщення «після паузи»; ні або без відповіді: «Повернулась сама?»
  3. «Чекаємо: завантаження» → «Сьогодні»
  4. «Сьогодні, стан: після паузи — без лічильників і докору» — цей стан
  5. «Висить незроблений крок з до паузи?» — так → «Він досі актуальний?»
  6. «Сьогодні: наступний крок» → «Прийняла найперший крок для продовження?»
  7. так → «Крок із собою: крок із собою» → «Успіх: продовжила з того місця, де зупинилась»; ні → «Дорога» → «Дорога, стан: на паузі»
