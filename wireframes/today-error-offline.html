Розгорнути

Відмітка не загубиться: збережемо, щойно зможемо.

Екран: Сьогодні · Стан: помилка — немає зв'язку, видно останнє відоме · Файл: today-error-offline.html

Job екрана: E1 «Відчувати рух» — «Коли минає день, я хочу відчувати, що зробила щось для своєї цілі, щоб бути задоволеною своїми діями.» [?] — залежить від O18. Main job J0 тут не закривається: екран подає рух, а закриває його «Дорога».

Що на сторінці: повторна спроба не допомогла. Видно останнє відоме — станом на 08:40, як у стані «помилка». Кнопки «Спробувати ще раз» немає: повтор уже не допоміг, а друга кнопка зациклила б flow. У flow J0 далі тупик «свіжого руху не видно, доки немає зв'язку». У продукті вихід є: рух записується й відмічається, лягає з позначкою «збережемо, щойно зможемо», а плаваючий крок видно з останнього відомого (sitemap.md, «Наскрізні»: «немає зв'язку: крок дня видно з останнього відомого, відмітки чекають»). Без зв'язку збереження не триває, тож спіннера немає — одразу нерухома позначка (рішення 25).

Куди далі за flow J0:

  • Кінець flow: «Тупик: свіжого руху не видно, доки немає зв'язку». На сторінці він не глухий: новий рух записується й не губиться
  • Гілка «ні»: «Записати» → «Чекаємо: зберігаємо» без зв'язку не триває → «Збережено?» ні → Сьогодні — збережемо, щойно зможемо → місток «крок ліг на дорогу» → «Дорога»
  • Гілка «так»: плаваючий «Зроблено» → «Крок із собою» → «Збережено?» ні → Крок із собою — збережемо, щойно зможемо → місток → «Дорога»
  • Зв'язок повернувся → день оновиться сам; такого ребра у flow J0 немає [?]
  1. «Зробила щось для цілі й відкриває продукт»
  2. «Чекаємо: завантаження» → «Дані завантажились?» — ні
  3. «Помилка: дані не завантажились» → «Повторна спроба допомогла?» — ні
  4. «Немає зв'язку: видно останнє відоме» — цей стан
  5. «Тупик: свіжого руху не видно, доки немає зв'язку» — на сторінці вихід: «Записати» й «Зроблено»
