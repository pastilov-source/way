# wireframes/

Продуктовий дизайн: інформаційна архітектура, флоу, вайрфрейми.

**Стан 2026-10-06:** структура, сценарії й каркаси всіх восьми flows готові — 59 сторінок п'яти екранів; критика проведена й виправлена.

| Файл | Що це |
|---|---|
| `sitemap.md` | Сутності, дерево екранів, стани, навігація, трасування, рішення виконавця. Джерело правди для структури |
| `flows.md` | Вісім user flows у Mermaid |
| `audit.md` | Критика sitemap і flows та рішення, якими її закрито |
| `_screens.md` | Замовлення на каркаси: екрани головного flow J0, їхні jobs, місце у flow і чотири стани |
| `_conventions.md` | Правила каркасів: деталізація, розмітка, текст, назви файлів, стани, що лишаємо на потім |
| `_critique.md` | Критика каркасів 2026-10-06: таблиця дефектів, що полагоджено, що прийнято, що відкрито |
| `_wireframe.css` | Спільні стилі каркасів за `_conventions.md`: палітра й шрифти way-tau, мітки зон |
| `today.html` | Каркас «Сьогодні», стан «успіх»; поруч — `today-empty`, `today-error`, `today-loading` і стани інших flows. Повний перелік сторінок — `_conventions.md`, розділ 4 |
| `step.html` | Каркас «Крок із собою», стан «успіх»; поруч — `step-error`, `step-loading`, заглушка `step-empty`, вікно, телефон і сповіщення |
| `road.html` | Каркас «Дорога», стан «успіх»; поруч — `road-empty`, `road-error`, `road-loading` і стани інших flows |
| `new-road.html` | Каркас «Нова дорога», стан «успіх»; поруч — `new-road-empty`, `-error`, `-loading`, `-proposal`, `-questions`, `-draft` і стани збереження |
| `week.html` | Каркас «Тиждень», стан «успіх»; поруч — `week-empty`, `-error`, `-loading` і стани flow J1 |
| `ia.html` | Зведена сторінка для сайту. Збирається з `sitemap.md` і `flows.md` скриптом `tools/build_ia.py`; руками не правити |

Порядок: IA → ключові флоу → екрани low-fi → перевірка на чотири питання з `CLAUDE.md` §11.

**Скрипти** — у [`tools/`](../tools/README.md): `wf_tree.py` вставляє дерево каркасів і перемикач станів і тримає перелік сторінок, `wf_audit.py` звіряє набір, `wf_review.py` проганяє критику. Після будь-якої правки каркасів — усі три.
