# concept/

Концепція продукту: метафора в інтерфейсі, ключові механіки, продуктові рішення до візуалу.

Що тут має з'явитися:
- модель об'єктів (дорога, етап, крок, прогулянка, точка старту) і зв'язки між ними;
- механіка кроку дня — цифровий еквівалент вирваного аркуша з блокнота (`CLAUDE.md` §3);
- механіка щотижневого вибору фокусу;
- розв'язання суперечностей §9: одна дорога чи три, стрік проти провини, веб проти кишені.
